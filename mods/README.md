# mods/

Your own effects. Each folder with an `index.tsx` that exports an effect shows up in the app under **Mods**.

- New one from the template: `pnpm new-mod "my effect"`
- Example: [`sticker-slap/`](sticker-slap/index.tsx)
- Guide: [docs/mods.md](../docs/mods.md) · [en español](../docs/mods.es.md)

`index.generated.ts` is written by the app; don't edit it.
