# Caption fonts

They ship inside the project so the preview and the export work offline and always look the same.
Only the Latin subset (covers accents, ñ, ¿ and ¡), downloaded from Google Fonts.

- `montserrat-latin.woff2`: Montserrat (variable, weights 100–900). Bold yellow, Karaoke and Pop styles.
- `bangers-latin.woff2`: Bangers. Comic style.
